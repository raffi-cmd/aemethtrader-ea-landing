## 🚀 Getting Started Locally

1. Clone or download this repository.
2. Open `index.html` directly in any browser, or run a lightweight local server:
   ```bash
   # Python
   python -m http.server 3000

   # Node.js
   npx serve .
   ```
3. Visit `http://localhost:3000`.
